# AI Auto-BOQ & Material Price Predictor

โปรแกรมถอดแบบและประเมินราคาก่อสร้างบ้านอัตโนมัติ (BOQ) พร้อมพยากรณ์ราคาวัสดุก่อสร้างในไทย
กรอกผังห้องแล้วได้ใบประมาณราคา คิด Factor F แยกตามหมวดงาน นำเข้าผังจากไฟล์ DXF และพิมพ์ใบสรุปเป็น PDF ได้

- เปิดใช้งาน: https://ชื่อผู้ใช้.github.io/ai-auto-boq/
- ราคาวัสดุอัปเดตอัตโนมัติทุกวันด้วย AI (GitHub Actions + Claude web search)
- ใช้ประเมินเบื้องต้นเท่านั้น คลาดเคลื่อนได้ราว ±15–20%
